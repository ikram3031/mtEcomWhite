# [AB-64] Add Range-Based KPI Endpoint for Dashboard

## Summary
- Added dynamic date range calculation and previous period comparison logic in `DashboardController.js`.
- Implemented `/kpi` endpoint to return aggregation statistics for Sales, Orders, AOV, and Members.
- Registered `/kpi` route in `DashboardRoute.js`.

## Affected Files
- `backend/src/core/controllers/DashboardController.js`
- `backend/src/core/routes/DashboardRoute.js`

## Business Impact
- Enables the dashboard UI to display comparative date range (Today, Last 7 Days, Last 30 Days, Last 3 Months) performance metrics dynamically.
