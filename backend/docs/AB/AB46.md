# [AB-46] Refactor Email Templates & Implement Non-Blocking Order Email Dispatch Pipeline

## Change Summary

- **Module**: Backend (`src/templates/`, `src/core/utils/`, `src/core/controllers/OrdersController.js`)
- **Impact**: OTP Verification Email (`POST /api/v1/auth/register`), Customer Order Invoice Email, Admin Order Notification Email (`POST /api/v1/orders/new-order`)
- **Description**: 
  - Standardized all email templates (`otpEmailTemplate.js`, `orderInvoiceEmailTemplate.js`, `adminOrderEmailTemplate.js`) to use Google Web Fonts (`'Marcellus'` for titles/headings and `'Geist Mono'` for body/main content) with centered text alignment and `#F5F5F5` outer wrapper with `#121215` obsidian dark container cards and `#C5A059` gold accents.
  - Eliminated CID email attachments by hosting an ultra-optimized `logo_horizontal.png` (compressed ~85% to ~26KB) at `https://server.decantrebd.com/uploads/logo_horizontal.png`, preventing email clients (Gmail/Yahoo) from showing attachment pills in user inboxes.
  - Added `sendOrderEmailsAsynchronously` in `src/core/utils/orderDelivery.js` and hooked it into `createOrder` in `OrdersController.js`. Email dispatches run in isolated `setImmediate` blocks so SMTP latency or failures will never block or fail customer order placement.
  - Configured admin order notification dispatches to send to `decantre.store@gmail.com` and database Super Admin/Owner users, explicitly excluding `ikramul.web@gmail.com`.

## Business & Technical Impact

- **Zero-Latency Checkout**: Customer checkout API returns HTTP 201 immediately without waiting for SMTP network handshakes.
- **Inbox Cleanliness**: No `logo.png` attachment pills appear next to emails in Gmail/Yahoo inbox lists.
- **Visual Consistency**: All transactional emails strictly adhere to Decantre's luxury dark & gold visual identity.
