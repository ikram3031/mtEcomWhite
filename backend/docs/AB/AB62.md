# [AB-62] Optimize OTP Verification to Directly Activate Registered Members

## Change Summary

- **Module**: Backend (`src/core/controllers/MembersController.js`)
- **Impact**: Customer Registration & Verification Flow
- **Description**: Updated `verifyMemberOtp` to check for `context: "register"` in the request body. If present, it bypasses the password reset activation flow, directly sets `isEmailVerified: true` and `emailVerifiedAt` in the database, and returns the authentication token bundle (`issueMemberTokens`), logging the user in instantly.

## Affected Files

- `backend/src/core/controllers/MembersController.js`

## Business & Technical Audit

- **Zero Regression**: Forgot password and login verification flows for unverified accounts remain completely functional and secure.
- **Enhanced UX**: Newly registered members are logged in immediately upon OTP verification without being forced to reset their password.
