# [AB-63] Integrate Google Authenticator 2FA Logic for Dashboard Users

## Change Summary

- **Module**: Backend (`src/core/controllers/AuthController.js`, `src/core/controllers/TwoFactorController.js`, `src/core/routes/AuthRoute.js`, `src/core/models/user.model.js`)
- **Impact**: Security & Dashboard Authentication
- **Description**: 
  - Integrated `otplib` and `qrcode` for Time-based One-Time Passwords (TOTP) support.
  - Added `twoFactorSecret` and `twoFactorEnabled` to the User schema, ensuring the secret is selecting-out by default and deleted from JSON responses.
  - Refactored `/auth/login` to return `{ requires2fa: true }` upon password success.
  - Implemented `/2fa/send-qr` to generate a secret and email the QR code inline attachment.
  - Implemented `/2fa/verify` to validate the 6-digit TOTP token and issue access/refresh tokens.

## Affected Files

- `backend/src/core/models/user.model.js`
- `backend/src/core/controllers/AuthController.js`
- `backend/src/core/controllers/TwoFactorController.js`
- `backend/src/core/routes/AuthRoute.js`

## Business & Technical Audit

- **Zero Regression**: Customer/member login and standard APIs remain untouched.
- **Improved Security**: Mandates a 2FA step for all store administration panel logins.
