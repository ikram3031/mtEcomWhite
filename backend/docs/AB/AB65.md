# [AB-65] Add Order Status Distribution Endpoint for Dashboard

## Summary
- Implemented `getOrderStatusDistribution` endpoint in `DashboardController.js` to aggregate and return the count of orders grouped by their pipeline statuses (processing, shipped, completed, cancelled) for the selected date range.
- Registered `/orders/status-distribution` route in `DashboardRoute.js`.

## Affected Files
- `backend/src/core/controllers/DashboardController.js`
- `backend/src/core/routes/DashboardRoute.js`

## Business Impact
- Enables visualization of the order pipeline health and quick identification of workflow workflow bottlenecks.
