# Antigravity Dashboard Change Logs (AD03)

### AD03: Fix process.env undefined crash in Vite Dashboard

* **Date**: 2026-08-09
* **Impact**: Dashboard (`api-client.js`) — critical fix
* **Description**: The dashboard app was throwing a `ReferenceError: process is not defined` in production due to accessing `process.env.NEXT_PUBLIC_API_BASE_URL` without checking if `process` was defined. Vite does not polyfill `process` by default in the browser, causing the entire module to fail to load and the app to crash. The continuous auto-reload behavior observed could have been triggered by the environment or just the user trying to recover from a blank screen. This fix safely wraps `process.env` access.
* **Changes**:

  - Modified [`src/lib/core/api-client.js`](file:///C:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/lib/core/api-client.js) similarly.
