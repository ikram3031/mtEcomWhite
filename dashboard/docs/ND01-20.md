### ND06: Fix Product Edit Page Loading Error and Add Image Upload Validation
* **Date**: 2026-08-08
* **Impact**: Dashboard (Product Edit, Product Add, Image Validation, Routing)
* **Description**: Fixed critical bug where clicking any product to edit showed "Failed to load product details." error — caused by using a broken `window.location.pathname` hack to extract the product ID instead of React Router v6's `useParams()` hook. Also fixed `imageUrl` not being saved to the database when uploading a new image during product create/update. Added strict frontend validation to block form submission if no product image is selected or already uploaded.
* **Changes**:
  * Replaced `window.location.pathname.split('/').pop()` with `useParams()` in `productDetails.jsx` — resolves product edit page 404 error.
  * Fixed `imageUrl: finalMainImageUrl || undefined` → `imageUrl: finalMainImageUrl || ""` in `newProduct.jsx` and `productDetails.jsx` so uploaded image URL is always sent to the backend.
  * Added `thumbnailUrl` to product create body in `newProduct.jsx`.
  * Added frontend image required validation: if no image file or existing URL, form submit is blocked with a clear toast error message.
