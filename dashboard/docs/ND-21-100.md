# ND23: Dashboard Header, Sidebar Theme and Order Status UI Refactor

- **Description**: Refactored the dashboard overview to display a fixed 30-day date range with dynamic date calculation. Redesigned `OrderStatusPie` chart using distinct status colors (green, blue, gold, red) and clean tabular legend. Updated top header and sidebar header to matching fixed heights (`h-16`) and dark backgrounds (`bg-zinc-950`) even in light mode. Configured collapsed sidebar to maintain a dark background across light and dark modes.
- **Affected Files**:
  - `dashboard/src/pages/dashboard/overview.jsx`
  - `dashboard/src/components/core/dashboard/OrderStatusPie.jsx`
  - `dashboard/src/components/core/dashboard/app-sidebar.jsx`
  - `dashboard/src/components/core/dashboard/header.jsx`
  - `dashboard/src/components/core/ui/sidebar.jsx`
- **Impact**: Improves visual consistency across light/dark modes and enhances UX for order pipeline tracking and header alignment.
