# [AF-18] Send Registration Context in OTP Verification and Log In Directly

## Change Summary

- **Module**: Frontend (`src/components/AuthModal.jsx`)
- **Impact**: Customer Registration & Verification Flow
- **Description**: 
  - Passed `context: otpContext` inside `verifyMemberOtp` call in `AuthModal.jsx` during OTP submission.
  - Set `otpContext` to `'login'` when launching the OTP flow from unverified login attempts to differentiate it from registration.
  - Extracted access/refresh tokens from the verify OTP response and passed them into `setUser(verifiedUser, tokens)` to log the user in instantly upon successful verification.

## Affected Files

- `frontend/src/components/AuthModal.jsx`

## Business & Technical Audit

- **Zero Regression**: Forgot password flow remains intact and unaffected. Unverified login flow still redirects to password reset/activation.
- **Enhanced UX**: Users are automatically logged in upon successful OTP verification without unnecessary redirection or password resets.
