# [AF-17] Redesign Phone Number Field with Fixed +880 Prefix Block in AuthModal

## Change Summary

- **Module**: Frontend (`src/components/AuthModal.jsx`)
- **Impact**: Customer Registration Modal (`AuthModal`)
- **Description**: 
  - Redesigned the phone number input block in `AuthModal` to display a fixed, read-only `+880` country code prefix block matching the dashboard design system rules.
  - Refactored `normalizePhoneValue` to strip leading zeros and non-digit characters so users can type either `01XXXXXXXXX` or `1XXXXXXXXX` without validation errors.
  - Refactored `validatePhoneValue` to validate the 10-digit suffix by appending `+880` and testing against Bangladeshi mobile regex (`/^\+8801[3-9]\d{8}$/`).
  - Automatically prepends `+880` to the stored 10-digit suffix during form submission (`handleRegister`), ensuring 100% compliance with backend schema constraints without user friction.

## Affected Files

- `frontend/src/components/AuthModal.jsx`

## Business & Technical Audit

- **Zero Regression**: Login, OTP Verification, Password Reset, and MyAccount profile flows remain completely untouched and fully functional.
- **Enhanced UX**: Prevents formatting errors and invalid input rejections during customer registration.
