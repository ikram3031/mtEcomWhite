# [A-01] Fully White-Label Client Setup & Dynamic Compose Volume Mounting

## Change Summary
- **Module**: Root Configuration / Setup Script (`client-setup.sh`, `docker-compose.prod.yml`)
- **Impact**: Deployment & Infrastructure Management
- **Description**:
  1. Refactored `client-setup.sh` to accept a dynamic client name as a command argument (`bash client-setup.sh <client_name>`) instead of using a hardcoded `decantre` path.
  2. Updated the script to dynamically initialize client config storage at `/opt/<client_name>/configs` and uploads at `/opt/<client_name>/uploads`.
  3. Modified `docker-compose.prod.yml` to replace the hardcoded `/opt/decantre` paths with the dynamic environment variable `/opt/${CLIENT_NAME}`.
  4. Updated Docker Compose network identifiers and container volume bindings to use the dynamic setup.

## Affected Files
- `client-setup.sh` — Updated directories to use dynamic argument
- `docker-compose.prod.yml` — Switched volume paths to use `${CLIENT_NAME}` variable
