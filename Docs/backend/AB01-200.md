# Backend Change Logs (AB01 - AB200)

This document tracks backend module changes, features, and API implementations.

# [AB90] Recursive Subcategory Resolution in Product Filter
## Change Summary
- **Module**: Backend Product Query Builder (`backend/src/utils/productUtils.js`)
- **Impact**: Single-request category filtering that automatically includes all child and subcategory products without frontend multi-call workarounds
- **Description**:
  1. **Recursive Subcategory Resolution**: Updated `buildProductFilter` so when querying products by category slug, DID, or ID, it recursively queries and aggregates all descendant/child category ObjectIds (`parent: { $in: currentParentIds }`).
  2. **Eliminated Partial Regex Duplication**: Removed ambiguous substring matching in category query to ensure clean exact matches and hierarchy-based product aggregation.

# [AB89] Meta Conversions API (CAPI) Server-Side Purchase Event Integration
## Change Summary
- **Module**: Backend Orders Controller, Environment Configuration & CAPI Service (`backend/src/config/env.js`, `backend/src/services/facebookCapi.service.js`, `backend/src/controllers/OrdersController.js`, `backend/.env`)
- **Impact**: 100% Reliable Server-Side Order Tracking with SHA-256 Hashed Identifiers and Test Event Code Support
- **Description**:
  1. **Environment & Schema**: Added `FB_PIXEL_ID`, `FB_ACCESS_TOKEN`, and `FB_TEST_EVENT_CODE` to backend `.env` and `src/config/env.js`.
  2. **CAPI Service**: Created `src/services/facebookCapi.service.js` with SHA-256 hashing for customer identifiers (`em`, `ph`, `fn`, `ln`, `ct`, `country` 'bd'), client IP / User-Agent detection, and event deduplication ID generation (`purchase_{orderNumber}`).
  3. **Non-Blocking Trigger**: Wired `sendServerPurchaseEvent` into `createOrder` controller alongside asynchronous order email notifications.

# [AB87] Cloudflare R2 Sync, Orphan Image Cleanup Scheduler & Admin Review APIs
## Change Summary
- **Module**: Backend Schedulers, Storage Services & Admin APIs (`backend/package.json`, `backend/src/config/r2.config.js`, `backend/src/models/mediaCleanupAudit.model.js`, `backend/src/models/r2SyncLog.model.js`, `backend/src/services/mediaAudit.service.js`, `backend/src/services/r2Sync.service.js`, `backend/src/schedulers/mediaScheduler.js`, `backend/src/dashboard/controllers/MediaAuditController.js`, `backend/src/dashboard/routes/mediaAuditRoute.js`, `backend/src/app.js`, `backend/src/server.js`)
- **Impact**: Zero Media Loss, Off-site Cloud Backup, Automated Storage Hygiene & Safe Admin Approval Workflow
- **Description**:
  1. **Package Version Bump**: Incremented minor version from `2.2.5` to `2.3.0` in `backend/package.json` and installed `@aws-sdk/client-s3`.
  2. **Cloudflare R2 Synchronizer**: Created S3-compatible R2 client helper and differential sync service (`r2Sync.service.js`) that compares local `/uploads` assets against Cloudflare R2 bucket keys and uploads missing files.
  3. **Orphan Media Scanner**: Implemented database reference aggregator (`mediaAudit.service.js`) scanning all active Products, Variants, Categories, Brands, and Meta documents to detect unused physical media on VPS disk without hard deletion.
  4. **Admin Approval & Review APIs**: Built protected endpoints under `/v1/api/admin/media-audit` (`/summary`, `/orphans`, `/scan`, `/r2-sync`, `/whitelist`, `/confirm`) enabling admins to view previews, whitelist false positives, and permanently delete approved orphan assets.
  5. **Background Schedulers**: Integrated cron/timer schedulers in `mediaScheduler.js` and hooked into server bootstrap and graceful shutdown in `server.js`.
