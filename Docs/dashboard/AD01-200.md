# Dashboard Change Logs (AD01 - AD200)

This document tracks dashboard module changes, features, UI/UX enhancements, and client tools.

# [AD02] Full Menu Access for Admin Across Client Configs and Reliable Version Display
## Change Summary
- **Module**: Dashboard RBAC, Multi-tenant Client Configs, Route Guard & Sidebar Version Display (`dashboard/src/clientConfig/*/config.json`, `dashboard/src/components/clientRouteGuard.jsx`, `dashboard/src/components/dashboard/app-sidebar.jsx`)
- **Impact**: Unrestricted full menu access for Admin across all tenants including Toyoland, wildcard route guard permissions, and robust version display in sidebar header, collapsed icon state, and user profile popover.
- **Description**:
  1. **Full Menu Access for Admin**: Updated `app-sidebar.jsx` so that `Owner`, `Admin`, `SuperAdmin`, and `Administrator` roles bypass restrictions and receive full wildcard access to all menus (including Tools -> Messages, Assets, Meta Catalog, Media, Billing, Analytics, etc.).
  2. **Multi-tenant Client Config Synchronization**: Added wildcard `"*"` and all missing menu keys (`tools.messages`, `billing`, `developer`, `settings`) to `allowedMenus` across `03toyoland/config.json`, `02engulfic/config.json`, and `01decantre/config.json`.
  3. **Client Route Guard Wildcard Handling**: Updated `clientRouteGuard.jsx` to validate wildcard permissions and mapped all newly added routes and tools.
  4. **Reliable Version Display**: Connected sidebar version display to `__APP_VERSION__` (with fallback to `package.json` version `3.2.5`), ensuring version `v3.2.5` renders in expanded sidebar header, collapsed menu, and user profile popover without clipping.

# [AD01] Messages Inbox in Tools, Direct SMTP Replies and Unified Notifications Bell

## Change Summary
- **Module**: Dashboard Tools, Messages View, Notification Bell & Navigation (`dashboard/src/pages/dashboard/tools/messagesManager.jsx`, `dashboard/src/components/dashboard/NotificationBell.jsx`, `dashboard/src/components/dashboard/app-sidebar.jsx`, `dashboard/src/router.jsx`, `dashboard/src/config/core.json`)
- **Impact**: Full interactive customer message inbox under Tools menu, direct email responses delivered to customer inboxes via SMTP, and unified notification dropdown supporting both order placements and incoming inquiries
- **Description**:
  1. **Messages Manager UI**: Built full master-detail split inbox view under `/dashboard/tools/messages` with status filter tabs (All, Unread, Replied, Read), real-time search, quick copy actions, message deletion, and threaded conversation display.
  2. **Direct SMTP Reply Composer**: Integrated in-app reply composer allowing store managers and admins to reply directly to customer inquiries. Replies are dispatched to customer email via store SMTP and stored in thread history.
  3. **Sidebar Tools Hierarchy**: Inserted **Messages** with a dedicated `Mail` icon as the **very first item** inside the **Tools** menu accordion in `app-sidebar.jsx`.
  4. **Unified Notifications Dropdown**: Refactored `NotificationBell.jsx` from "Order Notifications" to "Notifications", rendering custom badges/icons for both `newOrder` (ShoppingBag) and `contactMessage` (Mail) with intelligent routing to their respective dashboard pages.
  5. **RBAC & Router**: Configured `tools.messages` route guard permissions in `core.json` and registered routes and redirects in `router.jsx`.
